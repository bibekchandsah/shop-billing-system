ERROR 1: "Missing or insufficient permissions"
═══════════════════════════════════════════════════════════════════════════════

CAUSE: Firestore security rules are blocking writes

FIX (Takes 1 minute):

1. Go to: https://console.firebase.google.com/
2. Select: shopbillingsystem
3. Click: "Firestore Database" (left sidebar)
4. Click: "Rules" tab (at top)
5. DELETE everything
6. PASTE this:

   ┌────────────────────────────────────────────────────────────────────────┐
   │ rules_version = '2';                                                   │
   │ service cloud.firestore {                                              │
   │   match /databases/{database}/documents {                              │
   │     match /{document=**} {                                             │
   │       allow read, write: if true;                                      │
   │     }                                                                   │
   │   }                                                                     │
   │ }                                                                       │
   └────────────────────────────────────────────────────────────────────────┘

7. Click: "Publish"
8. Wait for: "Rules published successfully"

✅ DONE! Error 1 fixed.


ERROR 2: "ERR_BLOCKED_BY_CLIENT"
═══════════════════════════════════════════════════════════════════════════════

CAUSE: Ad blocker or privacy extension blocking Firebase

FIX (Choose ONE):

Option A - Use Incognito Mode (EASIEST):
   1. Press: Ctrl + Shift + N (Chrome/Edge) or Ctrl + Shift + P (Firefox)
   2. Go to: http://localhost:5175/
   3. Test your app
   ✅ Extensions disabled in incognito!

Option B - Disable Ad Blocker:
   1. Click ad blocker icon (uBlock, AdBlock, etc.)
   2. Click "Disable on this site" or power button
   3. Refresh page (F5)
   ✅ Firebase unblocked!

Option C - Whitelist Firebase:
   1. Open ad blocker settings
   2. Add to whitelist:
      • *.googleapis.com
      • *.firebaseapp.com
      • localhost
   3. Save and refresh
   ✅ Firebase allowed!

✅ DONE! Error 2 fixed.
